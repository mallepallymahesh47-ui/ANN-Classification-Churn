# 📊 Customer Churn Prediction System

A Machine Learning web application that predicts whether a bank customer will churn using a trained Artificial Neural Network (ANN) model.

---

## 🚀 Project Overview

This project uses a trained neural network model to predict whether a customer is likely to churn based on their demographic and account information.

The system:

* Takes customer details as input
* Applies preprocessing (encoding + scaling)
* Loads the trained model
* Predicts churn probability

---

## 🛠 Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* TensorFlow / Keras
* Streamlit


---

## 🧠 Model Details

* Model Type: Artificial Neural Network (ANN)

### Input Parameters

- **Geography**: Customer location
- **Gender**: Customer gender
- **Age**: Customer age (18-92)
- **Credit Score**: Customer credit score
- **Balance**: Account balance
- **Tenure**: Years as customer (0-10)
- **Number of Products**: Products owned
- **Has Credit Card**: Credit card status
- **Is Active User**: Activity status
- **Estimated Salary**: Customer salary
  
## Output

The model predicts if a customer is likely to churn (leave) or stay with the company.
